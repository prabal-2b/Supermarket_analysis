# Project Description --
    This project focuses on analyzing Superstore sales data using SQL and Power BI to identify sales trends, 
    category-wise performance, and country-wise business insights.

# Key Analysis --
    * Calculated total and Average sales per year.
    * Top saleing Category in every Country.
    * Top categories which bring most part of revenue.
    * Top categories which Gives Most of the profit.
    * country and categories sold in specific country.
    * Added some usefull visuals for better understanding.
    * and more.

# SQL Concepts Used --

    * Common Table Expressions (CTEs)** using `WITH`
    * Subqueries and Nested Queries**
    * Aggregate Functions:** `SUM()`, `AVG()`
    * Window Functions:** `ROW_NUMBER()`, `LAG()`
    * Data Ranking:** `ROW_NUMBER()` with `PARTITION BY`
    * Grouping and Sorting:** `GROUP BY`, `ORDER BY`
    * Conditional Logic:** `CASE WHEN`
    * String Functions:** `SUBSTRING()`, `INSTR()`
    * Date Functions:** `YEAR()`
    * Numeric Functions:** `ROUND()`
    * NULL Handling:** `IFNULL()`, `NULLIF()`
    * Column Aliasing** using `AS`
    * Sales and Profit Analysis**
    * Country-wise Category Performance Analysis**
    * Top-Selling Category Identification**
    * Year-over-Year (YoY) Sales Growth Analysis**
    * Previous-Year Sales Comparison**
    * Percentage Growth Calculation**
